# WP-01 Public discovery evidence

Issue #34 is exercised at the shared-domain, provider-adapter, cache-policy, artwork, macOS composition, and user-outcome boundaries. CI runs these tests as part of the retained package and Xcode result bundles in the `foundation-evidence` artifact.

| Acceptance | Executable evidence |
| --- | --- |
| `CAT-01` | `Anime365CatalogueClientTests` uses serialized synthetic `URLProtocol` responses to verify documented Series query fields, filters, typed identities, and field-tolerant Series/Episode/Translation mapping. `CatalogueDiscoveryTests.mergesPartialSeriesDetails` proves list and cached relationship fields survive partial detail refreshes. |
| `CAT-02` | `CatalogueDomainTests` and `CatalogueDiscoveryTests` verify immutable queries, opaque query-bound cursors, identity-based partial merge, 300 ms search debounce, and in-flight coalescing. `MiraioLaunchTests.testSearchQuerySurvivesDestinationChanges` retains a screenshot after navigating away and back. |
| `CAT-03` | `CatalogueDiscoveryTests` executes all four age bands: fresh (up to one hour), stale-while-refresh (one to 24 hours), visible failure fallback (24 hours to 30 days), and unusable (older than 30 days). |
| `CAT-04` | `BoundedCatalogueCacheTests` proves disk persistence, scoped Clear Cache, and least-recently-used eviction through injected budgets. Production budgets are 32 MiB memory and 128 MiB disk. |
| `CAT-05` | `ArtworkClientTests` verifies HTTPS-only public locations including alternative private-address forms, download/decode coalescing, transport/decode abandonment, the 20 MiB/40 MP caps, four-download/two-decode limits, decoded-image LRU pressure, and the five-redirect cap. `AppCompositionTests.derivesNextArtworkViewport` proves the visible-card count drives exactly one viewport of look-ahead; hidden destinations cancel their artwork work. Production policy resolves initial and redirected hosts and rejects any private result. |
| `CAT-06` | `Anime365CatalogueClientTests.mapsFlatSeriesDetails` verifies only documented flat relationships. Fixture-backed `MiraioLaunchTests` asserts the stable destinations and verifies that Series/Episode/Translation inspector selection survives destination changes, retaining screenshots of both outcomes. |
| `UX-01` | Fixture-backed launch and inspector tests verify the stable Catalogue/Search/Watch History information architecture, source list, hero, results, context preservation, and trailing inspector. String-catalog compilation plus `testRussianChromeIsAvailable` also verifies localized Russian chrome while provider metadata remains verbatim. |
| `UX-02` | The Catalogue dashboard deliberately renders Continue Watching as empty local Watch History-derived state, without invented activity. `testSearchQuerySurvivesDestinationChanges` verifies preserved user context across stable destinations. |
| `UX-03` | The retained launch screenshot verifies the cinematic dark canvas with glass limited to functional navigation, search, controls, and inspector surfaces. |
| `PRIV-02` | `Anime365CatalogueClientTests.usesPublicCatalogueNetworkPurpose` and `ArtworkClientTests.usesPublicArtworkNetworkPurpose` prove separate cookieless, credential-storage-free transports and bounded cache policy. DNS/public-address validation is executable in `rejectsAlternativePrivateAddressForms`; the dependency graph keeps credentials and playback in separate products. |
| `PERF-01` | `ArtworkClientTests` verifies HTTPS-public loading, identical download/decode coalescing, transfer and dimension rejection, cancellation during both transfer and decode, two-decode concurrency, decoded-image LRU pressure, and capped prefetch. `AppCompositionTests` verifies visibility-driven one-viewport-ahead demand. Production code bounds decoded memory at 128 MiB and uses cooperatively cancellable ImageIO downsampling off the caller actor. |
| `PERF-02` | `CatalogueDiscoveryTests` verifies demand-only cache behavior, identical-request coalescing, caller cancellation, five-minute cooldown, foreground recovery, bounded jitter, and a maximum of four concurrent remote operations. `mapsRetryAfterResponses` verifies numeric-fallback and HTTP-date retry semantics. Artwork separately caps downloads at four and decodes at two. |

Continue Watching is deliberately presented as an empty local Watch History-derived projection until WP-04. Playback controls remain unavailable until WP-06; WP-01 does not imply either capability exists.
