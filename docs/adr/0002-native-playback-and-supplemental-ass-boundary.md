# Keep native playback separate from supplemental ASS rendering

Miraio delegates transport controls, system playback integration, and recognized embedded or HLS legible tracks to AVKit, while an AVFoundation coordinator owns Playback Session timing and item lifecycle. External ASS is the sole V1 supplemental path: a bounded, capability-driven engine adapter renders against the active player-item timebase without networking, credentials, persistence, or independent playback control, and platform-specific hosts attach its output to the native player. This preserves authored subtitle fidelity and future iOS reuse without replacing the native player; core dialogue, timing, positioning, styles, overlaps, and signs remain release gates, while only advanced ASS effects may degrade.
