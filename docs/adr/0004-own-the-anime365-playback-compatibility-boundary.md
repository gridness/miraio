# Own the Anime365 playback compatibility boundary

Miraio will request playback information only through Anime365's documented Translation endpoint and Access Token flow, then interpret its open-ended success object through a versioned, Miraio-owned Playback Compatibility Profile. The initial real-time profile follows Ichime's empirically maintained `stream[].height` and `stream[].urls` shape, with optional `subtitlesUrl` or `subtitlesVttUrl`; one validated URL at a positive observed height becomes a Playback Candidate, while additional URLs carry no Source or failover meaning. Miraio will not copy Ichime's website-cookie authentication, subtitle proxy, or external-player handoff, and `a365dt` informs only documented token use and one bounded same-height reacquisition; its `download[]` shape is not an initial native path. Unknown or malformed shapes fail closed, protected responses and locations remain ephemeral, the Access Token is never propagated to media origins, and only Compatibility-Qualified Paths are advertised. This removes an unfulfillable dependency on provider-supplied types while explicitly accepting schema-drift risk, which decoder fixtures, redacted live shape evidence, and protected release qualification must contain; the supporting evidence and rejected alternatives are recorded in the [playback delivery research](../research/anime365-playback-delivery-contract.md).
