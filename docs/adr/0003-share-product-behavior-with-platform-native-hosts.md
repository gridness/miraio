# Share product behavior with platform-native hosts

Miraio places its domain, product state and policies, service contracts, and reusable Apple-platform adapters in a dependency-controlled local Swift package compiled and tested for macOS 26+ and iOS 26+, while only the macOS application ships now. Thin platform applications own dependency composition, lifecycle capture, presentation, navigation, localization, accessibility presentation, and native AVKit hosting; the shared Playback Session coordinator deliberately exposes its `AVPlayer` instead of replacing platform behavior with a lowest-common-denominator player abstraction. Protocols live beside their consumers, concrete adapters hide provider and framework details, mutable authorities use explicit actor isolation, and xrOS and a shared cross-platform UI are outside this architecture.
